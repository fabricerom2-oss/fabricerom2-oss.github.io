jarvis-youtube

A private publishing tool used by one YouTube creator to manage his own channels.

What it does

jarvis-youtube is a small desktop script used only by the owner of the channels SafeAI Watch and Océan Réel. It uses the YouTube Data API to:

  • upload videos that the owner produced to his own channels;
  • set titles, descriptions, tags, thumbnails and publication dates on those videos;
  • add videos to the owner's playlists;
  • read basic statistics (views, likes) of the owner's own videos.

It is not offered to the public and does not access any other user's data.
